# Curved Track 3D Model (OpenSCAD)
---
This repository contains generated OpenSCAD LEGO-compatible curved train track sections, based on the parametric model published on Printables:

https://www.printables.com/model/1710975-lego-compatible-parametric-ballasted-curved-train
---
### Information
---
This project exists solely to make available 3D files for track sections, ballast, and ballasted track, in the event that the original file is removed from Printables.
---

# Curved Track 3D Model (OpenSCAD)
---
Ce dépôt contient des générations OpenSCAD de rails de train courbes compatibles LEGO, basé sur le modèle paramétrique publié sur Printables :

https://www.printables.com/model/1710975-lego-compatible-parametric-ballasted-curved-train
---
### Information 
---
Ce projet à pour unique but de mettre à disposition des fichiers 3D des voies seules, des ballast, ainsi que des voies ballastés dans l'éventualité ou le fichier original se ferait retirer de printable.
